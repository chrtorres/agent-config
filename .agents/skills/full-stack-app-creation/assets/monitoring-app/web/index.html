A 3-STEP FIELD GUIDE

From signal to understanding.

  1. Start with the signals.

    Choose This host and Start monitoring for live observations, or Synthetic demo to explore fixture data.

  2. Ask a focused question.

    Run a quick baseline or a targeted check. Expand a result to inspect its exact command, time, exit code, and output.

  3. Keep the evidence.

    Review coverage, then export if useful. Suggested next steps require your judgment; this suite does not apply repairs.
