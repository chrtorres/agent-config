# Source-only local footage editor

Use the [standalone engine](../assets/footage-editor/) when the deliverable is a reusable local editor that reconstructs an interactive image-space performer directly from a caller-supplied recording. Select the [fixture-based viewer](footage-motion-review.md) for a synthetic demonstration or a project with authored shot geometry and reflections.

1. Copy the standalone engine into the requested application directory. Follow its [runtime setup](../assets/footage-editor/README.md) and install its pinned dependencies into an isolated Python environment. Check input format, usable foreground tracking, tmpfs capacity, compatible WebGL decoding, and availability of the generic inference models.
2. Start the launcher and receive the source path on standard input. Keep derived media, masks, anatomy, motion, and cleanup artifacts in a permission-restricted tmpfs session. Fetch only checksum-verified public model dependencies, or accept their verified offline copies. Avoid using past sidecars as inputs to a source-only validation.
3. Keep viewport zoom and pan independent of the video raster and the pose. Convert pointer and magnifier coordinates into source-raster coordinates. In a moved or reshaped view, invert the actual rendered mesh at the clicked point and apply the original foreground mask before selecting a region. For an unlabeled area, anchor relative to the nearest visible tracked region and use an adjustable finite support. Suspend the edit when its anchor or foreground coverage is unavailable.
4. Draw each decoded frame with its corresponding matte. Use original pixels away from the original and moved performer, and local source sampling at a revealed edge. Keep root movement and independent joint input separate from playback and from image cleanup. Preserve the original at neutral. Offer fine reshaping increments and use bounded triangle deformation for larger combined edits.
5. Serve only an explicit asset allowlist over an ephemeral loopback port. Disable request logging and set no-store on source, media, and all sidecars. Avoid persistent queues, account state, derived data, screenshots, and private filenames. Close the local service and remove the session's working files on exit. Document browser downloads, host swap, and other OS retention separately.
6. Regenerate in a fresh copy from an authorized input, using the source as the only subject-specific dependency. Exercise both rendering sizes, source byte ranges, seek, exact neutral reset, zoom and panning, direct and custom picking, shape changes, intact distant background, and disappearance when occluded. If an approved reference exists, compare same-frame native and 4K rasters at neutral and under deterministic controls. Keep real-source comparisons transient and record de-identified outcomes only.

The [model and media procedure](../../3d-modeling/references/footage-motion.md) covers inference and fidelity. The [capture inventory](source-only-footage-capture.md) describes the retained bundle.
