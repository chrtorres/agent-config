# Evidence-linked review applications

Use this pattern for an inspection interface that makes factual claims about a physical or digital object. The primary journey starts with a versioned artifact, exposes its inspectable structures, and connects what the user sees to the source or inference behind it.

1. Define the reference scope, intended use and limits in the product brief. Record source identity and version, the exact supported claim, conflicting observations, reconstruction decisions and what would justify a revision. Keep the observed fact, estimated parameter, and verification of the implementation distinct.
2. Create the smallest useful contract. Use stable identifiers for assemblies and their children. Define assembled presets, selection, framing, context visibility, descriptions, references and restore behavior. Store the artifact version and approval state where it can be read. A static same-origin package is sufficient when the app only reads versioned local content and stores view state per tab.
3. Commit visible state together. When the selection changes, update focus, title, reference context and visible geometry. Restore the previous visibility and transforms explicitly before applying the next group. Keep camera controls usable in failure states. Render supplied labels as text and accept only credential-free HTTP(S) reference links as actionable citations.
4. Test against the actual HTTP delivery path. Use a representative generated model and a smaller fixture. Verify inputs through the preparation command, asset loading, changed rendered pixels, selection and camera movement, recovery, restoration, keyboard access and narrow layouts. Wait for the actual render or settled transform before asserting. Add a deliberate failure case for each important test gate.
5. Ship the source-to-feature record, asset identity, runnable source, inspection tools, and limits together. A rendered interface and fully passing implementation tests establish behavior. Factual fidelity still depends on independent evidence about the object.
