# Nishikigoi material-variant example

Use the [material-variant workflow](../../references/material-variants.md) to generate this study in a new version directory. The generated assets are derived solely from the included Python sources. The viewer expects the generated catalog and variant files.

The bundled WebGL dependency is Three.js 0.180.0, including its core build, OrbitControls, GLTFLoader, and BufferGeometryUtils. The dependency is distributed under the [MIT license](review/vendor/LICENSE). [Upstream release](https://github.com/mrdoob/three.js/releases/tag/r180)
