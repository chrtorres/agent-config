# Combined review capture decision

The historical user wanted a contextual simulation, a scrubbable study and a previously authored exploded inspection in one review. The delivered project preserved reviewed model bytes and source metadata. Its local browser test verified switcher behavior, inactive clocks, and reassembly. The follow-up explicitly named both existing skills and the standalone repository for reuse.

| Existing skill | Coverage factors in rubric order | Score | Routing |
| --- | --- | ---: | --- |
| 3d-modeling | .75, .75, .75, 1, .75 | 78.75% | The GLB, animation, labeled assembly and synthetic fixtures directly support the workflow. Add composition, inactive lifecycle, path sampling and combined checks. |
| full-stack-app-creation | .75, .75, .75, .5, .75 | 71.25% | Existing animated playback and evidence-linked review cover UI state and frame validation. Extend the named skill as requested with shell architecture and the shared fixture. |
| smoke-test | .5, .5, .5, .5, .75 | 52.5% | It covers isolated rendering and evidence, with no combined-review behavior. Reuse the method and keep this capture in the named targets. |

| Material | Disposition |
| --- | --- |
| Original shell and activation protocol | Generalized to a manifest-driven packager, local tab shell and reusable child adapter. |
| Scene travel trace | Bundled a bounded time-stamped world-position sampler and rendering recipe. |
| Rig, anatomy geometry and simulated habitat | Original project assets remain task-local. Existing bundled Blender scripts regenerate the synthetic inputs. |
| Binary assets, screenshot captures and tests | Fresh source-driven reproduction with an executable browser harness. Generated outputs and current logs stay in external smoke evidence. |
| Supporting runtime | Blender, Python, Node.js, Playwright Chromium with WebGL, and the documented Three.js version are prerequisites. |

Historical feedback, paraphrased. The user wanted the live context to open first, with a compact way to reach movement and exploded inspection. The composition supports URL fragments and independent per-tab state. The reusable version exercises those interactions with regenerated inputs. Project identifiers, version paths, host and port values, renderer locations, and subject-specific data were parameterized or excluded. Browser and fixture checks establish integration behavior. Cross-scene pose synchronization and subject-level realism require a separate contract.
