# Runtime vegetation from an authored study

Use this workflow when placing reviewed trees or other repeated natural assets in a playable scene. Retain editable sources and the reviewed GLBs in their version directory. Identify the confirmed or pending review state and the distribution rights for modeled and referenced material.

1. Inventory each specimen's units, up axis, base anchor, height, spread, materials, named components and any motion pivots. Record the exact export hashes and required glTF extensions. Count triangles after expanding instances. A compact binary can still be expensive to draw.
2. Export specimen-only geometry. Keep unrelated terrain, studio lighting, inspection props and macro assets outside the runtime library. Use named structural and detail nodes so the consumer can retain the trunk and main limbs while thinning twigs, leaves or blossoms. Preserve recognizable rounded, spreading or pendant silhouettes at medium and distant viewing scales.
3. Check compression, instancing and embedded images with the target loader. Bundle compatible decoder and texture resources with the application. Preserve imported asset materials during integration, then tune displayed foliage, lighting, neighboring vegetation or ground litter in the host scene. Treat transforms and any runtime appearance changes as a separate integration record.
4. Orient wind pivots so branches and their attached details move together. Keep roots fixed. Inspect branch movement under the actual scene lighting and respect the host's reduced-motion setting.
5. Review a solitary landmark, a mixed grove and a wide approach with the gameplay camera. Include dusk or other scene-lighting variants if the application changes them. Carry these acceptance views into [the playable planting procedure](../../full-stack-app-creation/references/playable-vegetation.md).

The [synthetic generator](../scripts/create_planting_fixture.py) produces three editable Blender scenes, Draco-compressed GLBs with instanced crowns, and a manifest with byte hashes. The models demonstrate scale, silhouette and instancing with material colors. An authored study may additionally require textures, multiple wind pivots and custom attributes. Use the [isolated browser reproduction](../../full-stack-app-creation/references/playable-vegetation.md#isolated-reproduction) to verify the exported bytes through an actual application.
