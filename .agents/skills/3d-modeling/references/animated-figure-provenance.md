# Animated figure workflow provenance

The originating request asked for realistic full-circle motion from research, iterative testing, and a live preview. A real-species study connected published cadence and turning phases to an editable rig and a browser animation. The follow-up explicitly requested both named skills and the generic viewer receive a generalized implementation.

Historical feedback, paraphrased. The user wanted movement grounded in real observations and a preview from every angle. The implementation baked body movement separately from a traveling root and verified both, with separate limits for reconstructed fine motion. The subsequent request generalized this as clip playback for arbitrary figures and synthetic rig authoring. Retain independent figure-specific validation when fidelity to a measured subject is claimed.
